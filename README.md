# 鱼鱼档案库

和 AI 聊过的、值得留下来的东西，以及我自己写的、想到的、收集的。

## 两半

**读别人的**——同人、小说、游戏剧情、角色。聊完之后整理成条目。

**写自己的**——文章、点子、摘抄、想法。随手记进来，不必等它成形。

## 里面有什么

- **作品/** — 别人的作品。一部一个文件夹，`作品卡.md` 是入口
- **杂谈/** — 跨作品的讨论
- **创作/** — 我自己写的文章、片段
- **灵感/** — 点子、念头、还没长成的东西
- **摘录/** — 名言警句、好句好段
- **思考/** — 我的看法、分析、随想
- **模板/** — 各类的空白模板
- **说明书.md** — 写条目的完整规范，给 AI 看的
- **说明书-精简版.md** — 粘给 AI 用的一屏版
- **使用手册.md** — 日常怎么加、怎么找

## 怎么找东西

- **左侧边栏**：按大类，再按作品
- **顶部搜索**：角色名、台词片段、标签、句子，都能搜

## 怎么加一条

1. **生成**：在别的对话里，粘《说明书-精简版》，让它整理成条目
2. **交给我**：把整段回复贴过来，我把文件建好放进 `_待上传/`
3. **上传**：把 `_待上传/` 里的东西拖进 GitHub

完整流程见 [使用手册](使用手册.md)。

## 关于这个库

这个库是公开的，所以只放整理后的内容和短摘录。

名字里带「示例」的四个文件都是演示，看懂就可以删。
