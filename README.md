# 鱼鱼档案库

和 AI 聊过的、值得留下来的东西，以及我自己写的、想到的、收集的。

## 两半

**读别人的**——同人、小说、游戏剧情、角色。聊完之后整理成条目。

**写自己的**——文章、点子、摘抄、想法。随手记进来，不必等它成形。

## 里面有什么

- **作品/** — 别人的作品。一部一个文件夹，`作品卡.md` 是入口
- **杂谈/** — 跨作品的讨论
- **创作/** — 我自己写的文章、片段
- **灵感/** — 点子、念头、还没长成的东西
- **摘录/** — 名言警句、好句好段
- **思考/** — 我的看法、分析、随想
- **模板/** — 各类的空白模板
- **说明书.md** — 写条目的完整规范，给 AI 看的
- **说明书-精简版.md** — 粘给 AI 用的一屏版
- **使用手册.md** — 日常怎么加、怎么找

## 怎么找东西

- **左侧边栏**：按大类，再按作品
- **顶部搜索**：角色名、台词片段、标签、句子，都能搜

## 怎么加一条

- **和 AI 聊出来的**：把《说明书-精简版》粘过去，接一句「按这个整理」
- **自己写的**：从 `模板/` 复制一份，改个名存进对应文件夹

两种都要在 `_sidebar.md` 里加一行，否则搜不到。完整流程见 [使用手册](使用手册.md)。

## 关于这个库

这个库是公开的，所以只放整理后的内容和短摘录。

名字里带「示例」的四个文件都是演示，看懂就可以删。
