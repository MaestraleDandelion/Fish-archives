# 鱼鱼档案库

和 AI 聊过的、值得留下来的东西，以及我自己写的、想到的、收集的。

## 两半

**读别人的**——同人、小说、游戏剧情、角色。聊完之后整理成条目。

**写自己的**——文章、点子、摘抄、想法。随手记进来，不必等它成形。

- [帕特里琪娅的人设与伙伴感](作品/阿尔米奥西翁的医术师/2026-11-23_帕特里琪娅的人设与伙伴感.md) · 从日常后勤和一次分歧，看她怎样成为可靠的伙伴。

- [档案库更新记录](更新记录.md) · 看最近添了哪些内容入口和功能。

## 里面有什么

- **作品/** — 别人的作品。一部一个文件夹，`作品卡.md` 是入口
- **杂谈/** — 跨作品的讨论
- **创作/** — 我自己写的文章、片段
- **灵感/** — 点子、念头、还没长成的东西
- **摘录/** — 名言警句、好句好段
- **思考/** — 我的看法、分析、随想
- **视频/** — 按季节收藏的视频和感想
- **模板/** — 各类的空白模板
- **说明书.md** — 写条目的完整规范，给 AI 看的
- **说明书-精简版.md** — 粘给 AI 用的一屏版
- **使用手册.md** — 日常怎么加、怎么找
- **联系.md** — 怎么找到我

## 怎么找东西

- **左侧边栏**：按大类，再按作品
- **侧栏顶部搜索**：角色名、台词片段、标签、句子，都能搜

## 怎么加一条

1. **生成**：在别的对话里，粘《说明书-精简版》，让它整理成条目
2. **贴给我**：把整段回复贴过来，我直接写进档案库并推送

内容本来就在这儿聊的话，说一句「存成一条」就行。

完整流程见 [使用手册](使用手册.md)。

## 关于这个库

这个库是公开的，所以只放整理后的内容和短摘录。

名字里带「示例」的是归档演示。
